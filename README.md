# Design and Analysis of Algorithms

A collection of implementations, lab programs, assignments, and practice problems for **Design and Analysis of Algorithms (DAA)**.

This repository focuses on understanding algorithmic problem-solving, analyzing efficiency, and implementing commonly used algorithms with a focus on **time complexity, space complexity, and algorithmic paradigms**.

---

## 📚 About the Repository

The purpose of this repository is to maintain all the practical work and implementations related to the **Design and Analysis of Algorithms** course in one place.

The repository can be used for:

- DAA lab assignments
- Algorithm implementation practice
- Understanding time and space complexity
- Comparing different algorithmic approaches
- Exam and viva preparation
- Revising important algorithms and problem-solving techniques

## 📊 Algorithm Analysis

For each algorithm, the primary focus is on understanding:

| Parameter | Description |
|---|---|
| Time Complexity | Amount of computational time required |
| Space Complexity | Additional memory required |
| Best Case | Minimum work performed |
| Average Case | Expected performance |
| Worst Case | Maximum work performed |

### Example

| Algorithm | Best Case | Average Case | Worst Case |
|---|---:|---:|---:|
| Linear Search | O(1) | O(n) | O(n) |
| Binary Search | O(1) | O(log n) | O(log n) |
| Bubble Sort | O(n) | O(n²) | O(n²) |
| Insertion Sort | O(n) | O(n²) | O(n²) |
| Merge Sort | O(n log n) | O(n log n) | O(n log n) |
| Quick Sort | O(n log n) | O(n log n) | O(n²) |
